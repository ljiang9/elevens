# Elevens（纸牌接龙）

一个小巧的单机纸牌接龙游戏，玩法经典：

- **凑 11**：移走两张点数和为 11 的牌（A=1、2–10 按点数；J/Q/K 不参与凑数）
- **J-Q-K**：移走一组 J、Q、K（三张各一张，花色不限）

移走后库存会自动把空位补上。**把 52 张牌全部清掉即胜利**（约 5% 的牌局能赢，全看牌运）。

纯 Python 标准库，无外部依赖，可直接用 `python3` 运行。

## 运行

```bash
cd elevens
python3 -m elevens          # 交互模式：9 张牌，输入编号移牌
python3 -m elevens --seed 42
python3 -m elevens --auto --seed 7   # 贪心机器人自动玩
```

交互示例：

```
[0] A♠   [1] 10♥  [2] J♦
[3] Q♠   [4] K♥   [5] 5♦
[6] 6♣   [7] 9♥   [8] 3♠
选择牌（编号用空格隔开）> 0 1
```

`0 1`（A+10=11）被移走并从库存补两张；输入 `2 3 4` 移走 J-Q-K。输入 `q` 退出。

## 说明

- 桌面是 9 个位置（3×3），开局发 9 张，库存 43 张。
- 经典规则中 J/Q/K 不计点数，只能以 trio 形式消除。
- 机器人是贪心策略：优先拿 J-Q-K，再拿第一个 11 点对；仅用于快速验证，不保证最优。
